## HIG constraints (apply to all deliverables)

- **No squircle, no baked shadow** — free-form transparent canvas; compositor draws shadows.
- **Canvas**: hero 128px master (`source-logo.svg` 128 viewBox); symbolic 16px.
- **Grid**: 2px base grid; strokes snap to whole px at 16px.
- **Depth**: top-light plane + darker chin **≤4px** on front window; back window flat neutral (no gradient).
- **Palette**: 1–2 hues (violet + neutrals; grays don't count as hues). Flat fills preferred; at most one subtle vertical gradient on front window (light top → base).
- **Deliverables**: `source-logo.svg` (hero), `hicolor` full-color apps icons, `hicolor/symbolic` + tray, header mini SVG, `ico`/`icns` regen.

Palette (H1, flat):

- Front top-light: `#B79FF0` · front base: `#7C53C7` · chin (≤4px): `#5B3FA3`
- Back window: `#3A3A3C` (dark-gray neutral; light-theme legible, dark-theme distinct)
- Clock/focus dot + hand: `#FFFFFF` on violet (symbolic: `currentColor`)
- Outline (symbolic only): `currentColor`, 2px strokes converted to path

## 1/3 — Hero (app grid icon)

- **Canvas**: free-form transparent, `viewBox 0 0 128 128`, artwork ~112px optical, centered.
- **Composition** (back→front):
  1. Back window: rounded rect (~x28 y20 w64 h56, r8), flat `#3A3A3C`, offset up-left.
  2. Front window: rounded rect (~x36 y52 w64 h56, r8), violet base `#7C53C7`, top-light band `#B79FF0` (top ~40%), chin `#5B3FA3` bottom ≤4px.
  3. Clock/focus dot: white dot r6 at front-window center + single hand (2.5px, round cap) pointing ~2 o'clock; hand + dot merge at small sizes into one focus dot (intended).
- **Rules**: 2px grid; 1 hue (violet) + neutrals; no text, no shadow, no squircle.
- **Work**: replaces `icons/source-logo.svg`; render `icon-master.png` 1024²; regen via `tauri icon` (updates `32x32`, `128x128`, `128x128@2x`, `icon.ico`, `icon.icns`, carry-along sizes).
- **Accept**: legible at **32px** (dot/hand resolve to single dot; windows still read as two planes).

## 2/3 — Symbolic + tray

- **Master**: 16px monochrome, same metaphor simplified: two overlapping rounded-rect outlines + solid focus dot.
- **Spec**: `viewBox 0 0 16 16`, **2px strokes converted to path** (to outlines), round joins; dot r2 solid; gap ≥1px between back/front planes so they don't fuse at 16px.
- **Install**: `hicolor/symbolic/apps/com.saqr.wisp-symbolic.svg` (uses `currentColor`, no hard-coded color).
- **Tray**: reuses symbolic on Linux (`lib.rs` tray keeps existing show/quit menu; icon-only swap — keeps menu). No new tray code.
- **Usage rule**: full-color hero for app grid / app-switcher; symbolic for top bar, tray, and notifications.

## 3/3 — Header + packaging

- **Header**: `App.vue` brand mark — inline **flat mini redraw** of focus-window (two rects + dot, no gradients, `currentColor` for back + violet `#7C53C7` front, white dot); ~22px, same position beside wordmark. Delete old gradient defs (`ring-g`/`wisp-g`).
- **`Icon=`/metainfo**: new `.desktop`/`metainfo` entries point at **hicolor** (`Icon=com.saqr.wisp`); install hero PNGs/SVG under `hicolor/{size}/apps/`.
- **Tauri bundle**: `tauri.conf.json` `bundle.icon` list **unchanged** (still `32x32`, `128x128`, `128x128@2x`, `icns`, `ico`); `ico`/`icns` regenerated from new source.
- **Tests** (all must pass):
  1. App Icon Preview (GNOME) renders hero + symbolic without clipping.
  2. Light/dark theme check — back-window contrast holds on both.
  3. 16px symbolic legibility (dot + two planes distinguishable).
  4. `desktop-file-validate` clean on the new `.desktop` entry.

## Rejected alternatives

- **A — keep rose ring-wisp**: pretty but reads as media/loading spinner; fails at 16px; tied to old Rose accent.
- **B — clock-only**: generic, collides with Clocks app.
- **C — eye**: surveillance connotation; wrong for a privacy-first local tracker.
- **D — smoke puff**: illegible ≤32px, no windowing/time read.
- **E — letter W**: wordmark-dependent, weak at grid sizes, i18n-fragile.
- **G-colors** (non-violet): G1 keep-rose (rejected: old brand, low distinctness); G2 blue (rejected: **too common** in grid); G3 green (rejected: reads **online/available**, contradicts offline-privacy); G4 monochrome-only (rejected: vanishes among symbolic-style apps in full-color grid).
- **H2 blue / H3 green**: same reasons as G2/G3 — H2 lost in a sea of blue folders/browsers; H3 signals presence/online status.
